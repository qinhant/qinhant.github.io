# Qinhan Tan — Personal Website

Live website: https://qinhant.github.io/

A static academic homepage adapted from [Minimal Light](https://github.com/yaoyao-liu/minimal-light), with content migrated from https://sites.google.com/view/qinhantan/.

## Updating

Edit `index.html` to update the biography, publications, teaching, and honors. Styles are in `assets/css/custom.css`; the original theme stylesheet is retained in `assets/css/minimal-light.css`. The portrait is `assets/img/portrait.jpg`.

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` publish automatically. No build tools or dependencies are required.

For a local preview, run `python3 -m http.server 8000` in this folder and open http://localhost:8000.
